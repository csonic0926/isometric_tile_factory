# Cast pressure — optional method

Use when a cast is redundant, missing a story function or inactive despite rich
biographies. Inputs: current indexed characters, intended scope/story functions,
relevant relations and pressures. Output: one usable cast assessment/action set.

Compare what each person causes, knows, blocks, needs and can lose. A pair with
similar titles may exert different pressure; different descriptions can hide the
same dramatic job. Mark meaningful overlaps and uncovered functions, then test
whether relationships can place those functions in conflict in an actual scene.

Prefer concrete retain/revise/add requests with affected characters, reason,
priority and downstream effect. Don't invent people to reach a count or mutate
existing canon as a side effect of an audit. Preserve accepted characters and
route genuinely new character work to the continuing author, not a fixed worker
chain. The full cast result replaces separate scope/audit/rebalance handoffs.
