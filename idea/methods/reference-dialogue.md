# Reference-led product dialogue — optional method

Use when USER knows the desired work better than the model, or a reference is
being mistaken for an instruction to copy every feature. Inputs: actual USER
words, available reference evidence and existing adopted decisions.

Name one concrete player situation from the reference. Describe what appears
transferable and ask only the high-impact unresolved distinction. Contrast an
intentional difference without proposing a replacement product. If no productive
relationship exists, say so; do not mine features to justify the reference.

Keep source observations separate from hypotheses and chosen differences. A
small playable example may improve mutual understanding, but don't promote its
limitations into the product scope. Save decisions/reasons/unknowns directly in
the current exploration record. Stop probing settled matters; don't force a
thesis or commission merely because the conversation has enough material.
